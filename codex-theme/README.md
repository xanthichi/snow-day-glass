# Snow Day Glass

Created with the canonical CodexThemes theme creator. Version 0.13.0.

One continuous, uncropped winter artwork across the app. Reading surfaces use
20%, 78% and 70% white fills with no blur, black sidebar text and blue action
controls. Hovered or keyboard-highlighted choices retain local glass material.
Settings use a single 20% page fill without underlying text ghosting. Sticky
headings keep a clear white fill without blur, and file panes meet the outer
right border.
Comparison B uses full Projects and Plugins page veils and common white fills
at 20% opacity / 80% transparency. A remains available as v0.12.0 with 80%
opacity. The prior chat and output materials stay unchanged in both.

Typography uses local Consolas, Microsoft YaHei UI and Segoe UI, with system
fallbacks. No font files or font data are embedded. Artwork supplied by the user from
https://www.pixiv.net/artworks/139476242.

Codex++ uses a separate official user extension for local SDF refraction and
precise component styling because its DreamSkin ZIP uses restricted Safe CSS.
Verification scope is recorded in the repository's versioned QA documents.
