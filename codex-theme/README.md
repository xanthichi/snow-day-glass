# Snow Day Glass

Created with the canonical CodexThemes theme creator. Version 0.6.0.

One continuous, uncropped winter artwork across the app. Reading and composer
surfaces have no blur. Only hovered or keyboard-highlighted navigation, history
rows and menu candidates use a small iOS-inspired glass material.

Chinese typography: embedded LXGW WenKai GB, SIL OFL 1.1; English and digits:
local Consolas with system fallbacks. Artwork supplied by the user from
https://www.pixiv.net/artworks/139476242.

Static validation and offline previews passed. The new native theme has not
been applied to the user's live window. Codex++ per-row hover uses a separate
official user extension, because its DreamSkin ZIP uses restricted Safe CSS.
