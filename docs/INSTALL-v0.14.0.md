# Snow Day Glass v0.14.0 - 50% White Fill

Common white fill: **50% opacity / 50% transparency**.
The top application titlebar is **20% opacity / 80% transparency**.

1. Import `snow-day-glass-theme-v0.14.0.zip` in DreamSkin and apply it.
2. Run `pwsh -File extensions/Install-Glass.ps1`.
3. Use **Hot Reload Extensions** in Codex++.

Extract the complete ZIP first; import its nested theme ZIP. Use the matching
companion for full Projects/Plugins body coverage, optimized edge refraction
and native scrolling. Chat alpha 0.78 and tool alpha 0.70 remain unchanged.
No fonts are bundled.

A v0.12.0 is 80% opacity; B v0.13.0 is 20% opacity. To compare them, import
that version's theme ZIP and install its matching companion.
