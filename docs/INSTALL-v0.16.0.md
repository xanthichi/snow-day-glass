# Snow Day Glass v0.16.0

Global HTML typography: local Consolas for Latin/digits, Microsoft YaHei for
Chinese, with local fallback fonts. Sidebar labels and editable composer text
are pure black. Icons, mathematical fonts and semantic/syntax colors remain.

Saved only for this revision. No automatic import or live application was made.
For later manual installation:

1. Import `snow-day-glass-theme-v0.16.0.zip` in DreamSkin.
2. Run `pwsh -File extensions/Install-Glass.ps1` from this distribution.
3. Use **Hot Reload Extensions** in Codex++.

Extract the complete ZIP first; import its nested theme ZIP. The same-version
companion is required for global named fonts and precise text overrides:
Safe CSS permits only generic font families. Importing only the base ZIP
cannot enable the named font stack.
