# Snow Day Glass v0.17.0

Only change from v0.16.0: remove the newer native white gradient above the
thread composer. Fonts, colors, materials, input shadow and layout are unchanged.

Saved without automatic import/application. For a later manual update:

1. Extract the complete distribution ZIP.
2. Import `snow-day-glass-theme-v0.17.0.zip` through DreamSkin.
3. Run `pwsh -File extensions/Install-Glass.ps1`.
4. Use **Hot Reload Extensions** in Codex++.

The matching companion contains the precise native gradient cleanup. Importing
the base ZIP alone does not update an older installed companion.
