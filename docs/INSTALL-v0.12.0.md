# Snow Day Glass v0.12.0 - Comparison A

White fill: **80% opacity / 20% transparency**.

1. Import `snow-day-glass-theme-v0.12.0.zip` in DreamSkin and apply it.
2. Run `pwsh -File extensions/Install-Glass.ps1`.
3. Use **Hot Reload Extensions** in Codex++.

Extract the complete ZIP first; import its nested theme ZIP. Use the matching
companion for full Projects/Plugins body coverage and precise glass styling.
The page body now has a complete white veil; chat alpha 0.78 and tool alpha
0.70 remain unchanged. No fonts are bundled.
