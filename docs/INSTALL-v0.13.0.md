# Snow Day Glass v0.13.0 - Comparison B

White fill: **20% opacity / 80% transparency**.
A is v0.12.0 with 80% opacity / 20% transparency.

1. Import `snow-day-glass-theme-v0.13.0.zip` in DreamSkin and apply it.
2. Run `pwsh -File extensions/Install-Glass.ps1`.
3. Use **Hot Reload Extensions** in Codex++.

Extract the complete ZIP first; import its nested theme ZIP. Update both the
theme and companion so all common white surfaces match. Projects and Plugins
have complete page veils. Chat alpha 0.78 and tool alpha 0.70 stay unchanged.
No fonts are bundled.

To compare A, use its v0.12.0 complete ZIP and matching installer/companion.
Installing only an old theme ZIP does not change the newer companion.
