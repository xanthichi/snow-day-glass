# Snow Day Glass v0.15.0

Based on v0.14.0. Font-only update:

- Latin text and numbers: installed Consolas.
- Chinese fallback: installed Microsoft YaHei (微软雅黑).
- No embedded or downloaded font resources.

This version was saved without importing or applying it, as requested.
For a later manual installation:

1. Import `snow-day-glass-theme-v0.15.0.zip` in DreamSkin.
2. Run `pwsh -File extensions/Install-Glass.ps1` from this distribution.
3. Use **Hot Reload Extensions** in Codex++.

Extract the complete distribution first. Import only its nested theme ZIP.
The companion provides the named font stack because Safe CSS accepts only
generic font families. The v0.14.0 materials and performance changes remain.
